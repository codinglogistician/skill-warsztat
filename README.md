# Skill-warsztat — nauczcie agenta swojego fachu

**Sesja 3 · „Od promptu do produktu" · Rafał Jabłoński**

## Po co to jest

Przez dwie sesje Wasz agent dostał pamięć (CLAUDE.md) i dom (GitHub). Dziś dostanie
**umiejętność** — skill, czyli przepis wielokrotnego użytku, który wywołuje się jedną
komendą `/nazwa` i działa tak samo za każdym razem.

**Zadanie: w parze zbudować, przetestować i opublikować jeden skill dydaktyczny
— narzędzie, którego naprawdę użyjecie w swojej pracy na uczelni.**

Do wyboru trzy warianty (szczegóły w `KARTA_PRACY.md`):

| Wariant | Skill | Z czego korzysta |
|---|---|---|
| **A** | `/kartkowka` — generuje kartkówkę do importu w Moodle: GIFT + Moodle XML | `material/fragment_wykladu.md` + `przyklady/przyklad.gift` + `przyklady/przyklad.xml` |
| **B** | `/feedback` — informacja zwrotna do pracy studenta według rubryki | `material/esej_studenta.md` + `material/rubryka.md` |
| **C** | `/plan-zajec` — konspekt zajęć w stałym formacie z tematu i czasu | `material/fragment_wykladu.md` jako przykładowy temat |

## Czego to ćwiczenie NIE dotyczy

Nie oceniamy jakości pytań ani feedbacku na poziomie eksperckim — oceniamy, czy skill
jest **powtarzalny** (to samo wywołanie → ten sam format wyniku) i **przenośny**
(zadziała u drugiej osoby z pary bez tłumaczenia).

## Jak zacząć

Otwórz `INSTRUKCJA_UCZESTNIKA.md`. Pracujecie **w parach, w pokojach** — role
pilot/nawigator, zamiana w połowie. Fazy: `KARTA_PRACY.md`.
